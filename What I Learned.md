# What I Learned - E-Portfolio

## 1. Semantic HTML
I practiced using semantic HTML elements to organize a webpage.

## 2. CSS
I practiced styling webpages with colors, spacing, typography, borders, and backgrounds.

## 3. Flexbox
I used Flexbox to arrange navigation links and other page elements.

## 4. CSS Grid
I used CSS Grid to organize skills and project cards.

## 5. Responsive Design
I used media queries to make the portfolio work on smaller screens.

## 6. Git and GitHub
I practiced using Git to track changes and GitHub to store projects.

## Overall Takeaway
I learned how HTML, CSS, Flexbox, Grid, and responsive design work together to create a complete portfolio website.
